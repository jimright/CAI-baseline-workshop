# Shared Utilities

Common configuration and helper functions used across all modules.

| File | Purpose |
|------|---------|
| `config.py` | Centralized project configuration (model endpoints, data lake settings) |
| `data_connection.py` | Data lake connection utilities |
| `install-dependencies.py` | Package installation (runs on project bootstrap) |
| `cleanup_models.py` | Remove deployed models and registered versions |
| `reset.py` | Reset project state for re-running labs |
